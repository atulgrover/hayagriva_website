Local Serving Configuration

To execute these models locally without sending proprietary corporate insolvency data over the public internet, place the configuration below in your Hayagriva Desktop runtime:

# ~/.hayagriva/models.yaml - Sovereign Model Pipeline models: primary_reasoner: endpoint: "http://localhost:11434/v1" model: "haya-legal:7b" max_tokens: 4096 temperature: 0.1 forensic_avoidance: endpoint: "http://localhost:11434/v1" model: "haya-deepseek:14b" max_tokens: 8192 temperature: 0.0 embedding_engine: local_onnx_path: "./models/haya-embed-legal-v2.onnx" dimension: 1024 telemetry: allow_external_sockets: false enforce_airgap: true
