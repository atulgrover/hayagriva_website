Document Agents

Three Specialized AI Drafting Agents

Autonomous subagents integrated directly into the Harness drafting coordinator. Each agent handles a distinct drafting task and participates in a self-correction critique loop before presenting output.

@Document Agent

Primary Drafter

Assembles legal document drafts from DMS skeleton templates. Detects unresolved gaps and placeholders, queries the sovereign retrieval pipeline for supporting facts from the case knowledge base, and populates the skeleton.

CIRP Applications NCLT Petitions Form H Assembly Resolution Plans

@Forms Agent

Auditor

Acts as the critique agent in the self-correction loop. @Document delegates each draft to @Forms for compliance audit — statutory gap detection, missing mandatory sections, and statutory format verification. @Forms returns a structured critique list. @Document then refines the draft and presents only the verified final version to the user.

Gap Detection Statutory Format Check Mandatory Section Audit

@Advisor Agent

Research & Strategy

Handles research queries against the precedent vault and case knowledge base. Surfaces relevant judicial rulings, identifies Section 29A disqualification risks, and computes CoC voting share distributions — all locally without cloud dependency.

Precedent Research §29A Screening CoC Voting Shares PUFE Look-Back

Critique Loop — How Self-Correction Works

@Document generates draft → delegates to @Forms via the Harness autonomous critique protocol → @Forms returns a structured critique list → @Document refines the draft → verified draft presented to user. The user never sees the intermediate critique exchange — only the post-critique final output.

Version History

Every compiled DOCX is archived in drafts/history/ with a timestamp and version number. The DMS maintains a complete version history of all documents — no draft is ever permanently overwritten without an explicit user-confirmed action.
